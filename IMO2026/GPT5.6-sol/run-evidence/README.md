# Compact Run Evidence

These files preserve a small, reviewable subset of the final Problem 6
workflow evidence:

- `p6-proof-journal.jsonl` is raw structured workflow state for the proof graph,
  including normal reconciliation transitions, proved helper nodes, and the
  final target.
- `p6-final-verification.jsonl` records the final manager and project
  verification gates.

The records were generated by LeanFlow with `gpt-5.6-sol` at `xhigh` reasoning
effort through the Codex provider (`openai-codex` in persisted route metadata).
Absolute source-workspace paths were replaced with
`<workspace>/IMO2026/GPT5.6`, the archive's original directory name; no other
content was rewritten. The published directory was later renamed
`GPT5.6-sol` to distinguish it from the Luna run.

This is verification evidence, not a complete agent transcript. Exploratory
prompts, full provider responses, caches, credentials, and unrelated campaign
logs are deliberately excluded.
