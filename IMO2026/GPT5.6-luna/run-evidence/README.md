# Curated Campaign Evidence

This directory documents the stopped GPT-5.6-luna campaign without publishing
the full machine-local workflow state.

- [`campaign-summary.md`](campaign-summary.md) records the problem-by-problem
  outcome and the exact stopping condition.
- [`engineering-lessons.md`](engineering-lessons.md) separates correctness,
  liveness, organization, and performance findings that informed the LeanFlow
  redesign.

The raw campaign state was preserved locally before this archive was created.
It includes full activity logs, graph journals, checkpoints, verified-patch
receipts, and research dispatch records. The raw directory is intentionally
excluded here because it is hundreds of megabytes and contains redundant and
machine-specific operational material.
