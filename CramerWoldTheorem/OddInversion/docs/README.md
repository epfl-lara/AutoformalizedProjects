# Odd-Inversion Analytic Background

Downloaded on 2026-05-24 for the `OddInversion` proof subproject.

These files are local research references for the analytic theorem currently
isolated by `averageDistance_eq_odd_lintegral_of_boundedContinuous_nnreal`.
They are not imported by Lean.

## Files

| File | Source | Use |
| --- | --- | --- |
| `stanford_math220b_laplace.pdf` | https://web.stanford.edu/class/math220b/handouts/laplace.pdf | Fundamental solution of the Laplace equation; distributional proof outline for `-Delta Phi = delta_0`. |
| `stanford_math220b_greens_functions.pdf` | https://web.stanford.edu/class/math220b/handouts/greensfcns.pdf | Green functions and representation formulas. |
| `mit_18_156_lec0_fundamental_solutions.pdf` | https://ocw.mit.edu/courses/18-156-differential-analysis-spring-2004/62906408ea3a1fde43dee67b2c5ee0d0_lec0.pdf | MIT OCW overview of harmonic functions and fundamental solutions for the Laplacian. |
| `mit_18_303_greens_function.pdf` | https://ocw.mit.edu/courses/18-303-linear-partial-differential-equations-fall-2006/064b7e5d9e3296ab2219e44c53f7a1b5_greensfn.pdf | Delta function, Poisson/Laplace equations, and Green's function notes. |
| `wikipedia_fundamental_solution.html` | https://en.wikipedia.org/wiki/Fundamental_solution | Quick reference for the distribution-theoretic definition and Laplace examples. |
| `wikipedia_greens_identities.html` | https://en.wikipedia.org/wiki/Green%27s_identities | Quick reference for Green's first/second/third identities. |
| `proofwiki_1d_laplace_fundamental_solution.html` | https://proofwiki.org/wiki/Fundamental_Solution_to_1D_Laplace%27s_Equation | Useful base case: distributional second derivative of `|x| / 2` is `delta`. |
